## 版本内容说明

AIFlameUI 1.0版本是"视频AI智能识别及预警管理信息系统"的**前端Web管理系统**，基于Python Flask框架构建，负责系统全部前端界面的开发与质量保障。

### 技术栈

| 技术 | 用途 |
|------|------|
| Python Flask 3 | Web应用框架，页面路由与API服务 |
| Bootstrap 5 | 响应式UI框架，兼容PC端与移动端 |
| LayUI 2.9 | UI组件库，提升用户交互体验 |
| ECharts 5 | 数据可视化图表（折线图/柱状图/饼图/热力图） |
| 百度地图API v3 | GIS地图展示，摄像头标注与报警弹窗 |
| SQLAlchemy + SQLite | ORM数据库，用户/设备/报警/日志数据管理 |
| JWT (PyJWT) | 鉴权认证，与后端API对接 |

### 快速启动

```bash
# 1. 克隆仓库
git clone https://github.com/DlcFox/AIFlameUI.git
cd AIFlameUI

# 2. 创建虚拟环境并安装依赖
python -m venv .venv
source .venv/Scripts/activate  # Windows
pip install -r requirements.txt

# 3. 启动应用
python app.py

# 4. 浏览器访问
# GIS数据大屏: http://127.0.0.1:5000/
# 管理仪表盘: http://127.0.0.1:5000/dashboard
# 登录页面:   http://127.0.0.1:5000/login
```
